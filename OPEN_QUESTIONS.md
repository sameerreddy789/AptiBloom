# Open questions for the creators

None of these blocks the three-topic prototype. Answer them as research and pilot evidence becomes available.

## Audience and placement context

1. Which degree/year and college cohort should be the first user group?
2. Which companies or assessment platforms commonly recruit from that college?
3. Is the product only for campus placements or eventually for CAT, banking, government, and other exams?
4. How soon is the first real placement round?

## Curriculum

5. Which topics are being taught in the current aptitude class, in what order?
6. Should logical reasoning join maths and English in the first public MVP?
7. Are calculators permitted in the target tests?
8. Does verbal content follow Indian/British English conventions?
9. Who will author and independently review the first 90 questions?
10. What legitimate sources may be used for patterns without copying copyrighted question banks?

## Game and aesthetic

11. Does the skill-garden theme match the desired Gen-Z aesthetic, or would a city, space, campus, or journey theme feel better?
12. Should avatars be people, creatures, abstract icons, or optional?
13. How much animation and sound feels calm rather than childish?
14. Are friend squads important for launch or safe to postpone?
15. Should there be any public competition?

## Product

16. Is a mobile-first web/PWA acceptable, or is an Android app required immediately?
17. Should students be able to practise fully without an account?
18. Is English-only UI acceptable initially?
19. Which company-pattern simulation should be built first?
20. Do teachers/trainers need an assignment dashboard in the first campus pilot?

## Project and team

21. How many hours per week can each contributor commit?
22. What technologies do both contributors already know?
23. Who owns product/design, content, frontend, backend, and testing initially?
24. Is the repository intended to be public for résumés?
25. What is the target date for a demo to classmates?

## Current planning defaults

- Indian college campus-placement audience.
- Quantitative, logical, and verbal aptitude.
- Responsive PWA before native apps.
- Three-topic, 90-question prototype.
- Self-paced calm learning first; timed simulation later.
- Skill garden as working theme.
- Transparent rules-based adaptation.
- Private progress and optional social features.
- Human-reviewed content.
- Two-week pilot with 25–50 students before scaling the question bank.
